# 📂 Bash Automation Backup Script

A project designed to learn and implement automated data backup solutions using Bash scripting.
โปรเจคสำหรับเรียนรู้วิธีการเขียน Script เพื่อสำรองข้อมูลอัตโนมัติ (Automation)

---

## 🇺🇸 English Version

### 🚀 Key Features
- **One-Command Backup**: Execute the entire backup process with a single command.
- **Efficient Compression**: Compresses files into `.tar.gz` format to save storage space.
- **Auto-Timestamping**: Automatically generates unique filenames based on the current date and time.

### 🛠 How to Use
1. Open **Git Bash** (or any Unix-like terminal).
2. Run the script using: `bash backup.sh`
