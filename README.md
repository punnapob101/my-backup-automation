# 📂 Bash & Python Automation Backup Project

A project designed to learn and implement automated data backup solutions using Bash scripting and Python monitoring.  
โปรเจคสำหรับเรียนรู้วิธีการเขียน Script เพื่อสำรองข้อมูลอัตโนมัติและการตรวจสอบด้วย Python

---

## 🇺🇸 English Version

### 🚀 Key Features
- **One-Command Backup:** Execute the entire backup process using Bash.
- **Efficient Compression:** Compresses files into \`.tar.gz\` format to save storage space.
- **Auto-Timestamping:** Automatically generates unique filenames based on the current date and time.
- **Python Monitoring:** A smart script to verify backup integrity and file size.

### 🛠 How to Use
1. Open **Git Bash**.
2. Run the backup: \`bash backup.sh\`
3. Run the monitor: \`python monitor.py\`
